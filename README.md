# Pokémon GO Tracker — versão de teste

Projeto pessoal para acompanhar coleções shiny e shundo, Mega Evoluções e trocas combinadas.

Esta é a versão atual completa para testar a publicação. O histórico reconstruído das funcionalidades será publicado em outro repositório.

## Estrutura

- index.html: estrutura da página
- css/styles.css: estilos
- js/app.js: dados e funcionalidades

## Uso

Abra o link do GitHub Pages. O progresso fica salvo no navegador, sem sincronização entre dispositivos. Use Exportar/Importar backup para transferir suas marcações. Nenhum backup pessoal é incluído neste repositório.

Para executar localmente, abra index.html ou sirva a pasta com um servidor HTTP estático.

## GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, main e /(root).

## Créditos

Dados e imagens: [DittoBase](https://www.dittobase.com/pokemon-go/pokedex). Alguns ícones: [PokeMiners](https://github.com/PokeMiners/pogo_assets). Pokémon e Pokémon GO pertencem aos respectivos titulares. Projeto de fã, sem vínculo oficial.
